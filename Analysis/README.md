# Analysis

MATLAB post-processing code for comparing car-following calibration results obtained with different goodness-of-fit (GOF) functions.

The analysis operates on the validation reports generated by the `Calibration/` code and reproduces the comparative workflow distributed with:

> V. Punzo, Z. Zheng, M. Montanino, **About calibration of car-following dynamics of automated and human-driven vehicles: Methodology, guidelines and codes**, *Transportation Research Part C: Emerging Technologies*, 128, 103165, 2021.  
> https://doi.org/10.1016/j.trc.2021.103165

## Contents

```text
Analysis/
├── MAIN_ANALYSIS.m
└── Results/              # supplied by the user
```

`MAIN_ANALYSIS.m` reads the calibration validation reports, aggregates results across vehicles and models, computes absolute and relative statistics, and generates box plots comparing calibration GOFs under spacing-, speed- and acceleration-based validation criteria.

## Input required from `Calibration/`

The script reads files named:

```text
Validation_Report_CalExp_<n>_<GOF>.txt
```

produced by `Calibration/MAIN.m`.

The expected path is:

```text
Analysis/Results/<Project>/<Database>/<Folder>/Model <ModelID>/VehicleID <VehicleID>/Validation_Report_CalExp_<n>_<GOF>.txt
```

This is important: `MAIN_ANALYSIS.m` contains a separate `Folder` variable. Therefore the calibration results must either be placed under that additional folder level or `Folder` must be changed to match the directory structure you create.

For example, with:

```matlab
Project='NGSIM';
Database='Exp';
Folder='Stored/Results 1';
```

the script expects:

```text
Analysis/Results/NGSIM/Exp/Stored/Results 1/Model ...
```

## Configuration

Edit the setup block at the beginning of `MAIN_ANALYSIS.m` before running the script.

### Project and database

```matlab
Project='NGSIM';
Database='Exp';
```

These must match the corresponding calibration results.

### Results folder

```matlab
Folder='Stored/Results 1';
```

`Folder` identifies the subfolder containing the model/vehicle result tree.

### Models

```matlab
ModelIDs=[1,2,3,4];
```

Use the model IDs whose calibration results you want to compare.

### Experiments

```matlab
TotExperiments={'default'};
```

The default distributed calibration uses one experiment named `default`. The script uses the position of each element in `TotExperiments` as the calibration-experiment index when reading `Validation_Report_CalExp_<n>_...` files.

### Vehicles

Set `VehicleIDs` to the vehicles contained in the selected result set.

The source lists:

```text
NAPOLI:    1:9
JIANG:     [101,102,103,104,105,171,263,305,341,416]
NGSIM:     [607,705,770,797,978,1506,1593,1597,1649,1700,1754,3222]
ASTAZERO:  1:8
```

### Calibration GOFs to analyse

```matlab
SortedCalGOFIDs=1:length(textGOFs);
```

This determines which calibration GOFs are loaded and their order in the analysis. By default all 29 GOFs are included.

### Validation criteria

```matlab
ValGOFIDs=[1,2,3];
```

With the distributed `textGOFs` ordering these correspond to:

```text
1 → RMSE(S)   spacing
2 → RMSE(V)   speed
3 → RMSE(A)   acceleration
```

For each validation criterion, the script compares the result obtained after calibration with every selected GOF against the result obtained by calibration with the corresponding reference GOF.

## What the script computes

For each selected model, experiment, vehicle and calibration GOF, `MAIN_ANALYSIS.m` reads the corresponding validation report and extracts the GOFs identified by `ValGOFIDs`.

It then computes:

- raw validation values;
- relative differences with respect to the corresponding reference calibration GOF;
- mean;
- standard deviation;
- median.

The relative difference is computed as:

```text
(value - reference) / reference
```

for each validation criterion.

The statistics are retained in the MATLAB workspace in structures including:

```text
Stats
StatsRatio
```

with `Mean`, `Std` and `Median` fields.

## Box plots

The final section creates box plots of the relative calibration performance across the selected trajectories.

The current distributed script:

- uses spacing, speed and acceleration as validation dimensions;
- clips negative relative values to zero before plotting;
- displays values from `0%` to `>=100%`;
- uses the hard-coded `sortedIndex` ordering defined in the script;
- saves the MATLAB figure as:

```text
Analysis/Results/<Project>/<Database>/<Folder>/Boxplot.fig
```

If a different set of `ModelIDs`, GOFs or validation dimensions is used, review the plotting section and `sortedIndex` accordingly.

## Goodness-of-fit functions

The script uses the same 29-GOF ordering as the calibration code:

| ID | GOF |
|---:|---|
| 1 | RMSE(S) |
| 2 | RMSE(V) |
| 3 | RMSE(A) |
| 4 | RMSE(stdV) |
| 5 | RMSPE(S) |
| 6 | RMSPE(V) |
| 7 | RMSPE(A) |
| 8 | RMSPE(stdV) |
| 9 | MAE(S) |
| 10 | MAE(V) |
| 11 | MAE(A) |
| 12 | MAPE(S) |
| 13 | MAPE(V) |
| 14 | MAPE(A) |
| 15 | U(S) |
| 16 | U(V) |
| 17 | U(A) |
| 18 | RMSPEt(S) |
| 19 | RMSPEt(V) |
| 20 | RMSPE(stdV+S) |
| 21 | NRMSE(V+S) |
| 22 | RMSPE(V+S) |
| 23 | MAPE(V+S) |
| 24 | RMSPEt(V+S) |
| 25 | U(V+S) |
| 26 | NRMSE(V+S+A) |
| 27 | RMSPE(V+S+A) |
| 28 | MAPE(V+S+A) |
| 29 | U(V+S+A) |

## Run

1. Copy or organise the validation reports under `Analysis/Results/` using the path expected by `Project`, `Database` and `Folder`.
2. Edit the setup variables at the beginning of `MAIN_ANALYSIS.m`.
3. Set the MATLAB current folder to `Analysis/`.
4. Run:

```matlab
MAIN_ANALYSIS
```

The script leaves the calculated statistics in the MATLAB workspace and saves `Boxplot.fig` under the configured results folder.
