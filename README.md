# Car-following calibration

MATLAB codes and data supporting the car-following model calibration methodology and analyses presented in:

> V. Punzo, Z. Zheng, M. Montanino, **About calibration of car-following dynamics of automated and human-driven vehicles: Methodology, guidelines and codes**, *Transportation Research Part C: Emerging Technologies*, 128, 103165, 2021. https://doi.org/10.1016/j.trc.2021.103165

The package implements car-following model calibration through a genetic algorithm and post-processing of calibration results across different goodness-of-fit functions. It includes trajectory data and calibration configurations for human-driven and automated-vehicle experiments used in the study.

## Requirements

- MATLAB
- Global Optimization Toolbox, required by the genetic algorithm (`ga`)
- Parallel Computing Toolbox only if parallel calibration is enabled

No minimum MATLAB release is specified in the original package.

## Calibration

Run the calibration from `Calibration/Source/`.

### 1. Select the project and experiment

Edit:

```text
Calibration/Source/Data/setup.txt
```

The first value selects the project and the second value selects the experiment/database folder. The package contains:

- `NAPOLI`
- `JIANG`
- `NGSIM`
- `ASTAZERO`

Each project currently contains the `Exp` configuration.

### 2. Configure the calibration

Edit:

```text
Calibration/Source/Data/<PROJECT>/<EXPERIMENT>/config.txt
```

The configuration specifies:

- `ModelID`: model to calibrate
- `VehicleID`: trajectory or trajectories used for calibration
- `GOF`: goodness-of-fit function
- `PopSize`: genetic-algorithm population size
- `Parallel`: `0` or `1`
- `NumCPUs`: number of workers when parallel execution is enabled

For `VehicleID`, multiple IDs can be separated by commas. A value of `0` selects all available trajectories for the chosen dataset.

For `GOF`, multiple IDs can be separated by commas. A value of `0` runs the calibration using all available goodness-of-fit functions.

### 3. Model IDs

The bundled calibration configurations include:

- `1` — IDM
- `2` — Gipps
- `3` — Linear Controller with Constant Time Headway (CTH)
- `4` — Linear Controller with SIGMOID
- `999` — custom model

Parameter bounds are stored under:

```text
Data/<PROJECT>/<EXPERIMENT>/Bounds/Model Class <ModelID>/parameters.txt
```

For a custom model (`ModelID = 999`), the model formulation is read from `model.txt`; the parameter ordering follows `parameters.txt`.

### 4. Goodness-of-fit functions

The calibration code supports the 29 goodness-of-fit configurations listed in the original `Calibration/Source/readme.txt`, including RMSE, RMSPE, MAE, MAPE, Theil's U and combined measures based on spacing, speed and acceleration.

### 5. Run

From MATLAB, set the current folder to:

```text
Calibration/Source
```

and run:

```matlab
MAIN
```

Calibration outputs are written under `Calibration/Source/Results/`.

## Trajectory data format

Each vehicle trajectory file contains six columns:

1. time
2. leader position [m]
3. follower position [m]
4. leader speed [m/s]
5. follower speed [m/s]
6. leader vehicle length [m]

The trajectory files and the original configuration files distributed with the code are included unchanged.

## Analysis

The `Analysis/` folder contains the post-processing script used to compare calibration results across models and goodness-of-fit functions.

1. Copy the `Results` folder generated by the calibration into `Analysis/Results/`.
2. Edit the configuration variables at the beginning of `Analysis/MAIN_ANALYSIS.m`, including `Project`, `Database`, `Folder` and `ModelIDs`.
3. Run `MAIN_ANALYSIS.m` from MATLAB.
