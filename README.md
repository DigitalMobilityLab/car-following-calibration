# Car-following calibration

MATLAB codes and data supporting the car-following model calibration methodology and analyses presented in:

> V. Punzo, Z. Zheng, M. Montanino, **About calibration of car-following dynamics of automated and human-driven vehicles: Methodology, guidelines and codes**, *Transportation Research Part C: Emerging Technologies*, 128, 103165, 2021.  
> https://doi.org/10.1016/j.trc.2021.103165

The repository implements car-following model calibration through a genetic algorithm and post-processing of calibration results across different goodness-of-fit functions. It includes the trajectory data and calibration configurations distributed with the original code package.

## Requirements

- MATLAB
- Global Optimization Toolbox, required by the genetic algorithm (`ga`)
- Parallel Computing Toolbox only if parallel calibration is enabled

No minimum MATLAB release is specified in the original package.

## Calibration

The calibration code estimates model parameters from observed leader-follower trajectories using selectable car-following models and goodness-of-fit (GOF) functions.

Quick start:

1. Edit `Calibration/Data/setup.txt` to select the project and experiment.
2. Edit `Calibration/Data/<PROJECT>/<DATABASE>/config.txt` to select the model, trajectories, GOF and genetic-algorithm settings.
3. Set the MATLAB current folder to `Calibration/`.
4. Run:

```matlab
MAIN
```

The bundled datasets are:

- `NAPOLI`
- `JIANG`
- `NGSIM`
- `ASTAZERO`

The code supports the car-following model implementations and 29 GOF configurations documented in [`Calibration/README.md`](Calibration/README.md).

Calibration results are written below `Calibration/Results/`.

## Analysis

`Analysis/MAIN_ANALYSIS.m` post-processes the validation reports generated by the calibration code and compares calibration performance across different GOF functions.

To use it:

1. organise the generated validation reports under `Analysis/Results/`;
2. configure `Project`, `Database`, `Folder`, `ModelIDs` and the other setup variables in `MAIN_ANALYSIS.m`;
3. set the MATLAB current folder to `Analysis/`;
4. run:

```matlab
MAIN_ANALYSIS
```

See [`Analysis/README.md`](Analysis/README.md) for the expected results hierarchy and analysis settings.
